GET STARTED

Install. Import. Render.

Use a direct import to pick the icon and variant you want. Here is the Devicon logo in each framework.

React

import DeviconOriginalIcon from
  "@devicon/react/devicon/original";

<DeviconOriginalIcon size="2em" />

Vue

import DeviconOriginalIcon from
  "@devicon/vue/devicon/original";

<DeviconOriginalIcon size="2em" />

Svelte

import DeviconOriginalIcon from
  "@devicon/svelte/devicon/original/DeviconOriginalIcon.svelte";

<DeviconOriginalIcon size="2em" />

In a path like @devicon/react/react/original, the first react is the framework package; the second is the React logo in Devicon.
