SOUS LE CAPOT

Ce que fait ce dépôt.

Le dépôt contient les scripts de génération. Les icônes et les composants produits sont reconstruits à chaque build.

  1. 01

    Récupérer Devicon

    build-core télécharge la branche master de devicons/devicon dans tmp/devicon.

  2. 02

    Former le dossier core

    Le dossier icons/ et le fichier devicon.json sont copiés dans packages/core. Core sert de source interne au build.

  3. 03

    Générer les composants

    Les scripts React, Vue et Svelte transforment les SVG en composants et préparent chacun des trois packages.

  4. 04

    Publier une version

    Un tag Git vX.Y.Z déclenche GitHub Actions, qui reconstruit les packages et publie React, Vue et Svelte sur npm via OIDC.

MISES À JOUR

Les nouvelles icônes arrivent au prochain build.

Pas besoin de copier les fichiers Devicon dans ce dépôt. npm run build-all récupère la version courante de Devicon, puis régénère les trois packages.

Pour publier une nouvelle version npm, créez un nouveau tag et poussez-le sur GitHub. Un tag de préversion est publié sous next ; une version stable sous latest.

Suivre les builds GitHub Actions ↗

EXEMPLE · VERSION STABLE

git tag -a v1.0.0 -m "Release 1.0.0"
